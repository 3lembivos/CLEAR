# CLEAR:Composition of Likelihoods for Evolve And Resequence Experiments

##Overview
CLEAR is a tool for identifying selection in time-series pooled-sequencing data. The publication is available [here](https://pmc.ncbi.nlm.nih.gov/articles/PMC5499160/).


##Requirements
CLEAR is written in **python 2** which uses `seaborn`, `numba` and `pandas` packages.You can install required packages by running

`conda install pandas numba seaborn`

##Running
To obtain  CLEAR simply execute

`git clone --recursive https://github.com/airanmehr/CLEAR.git`
